# IoI-Framework

Indicator of Inconsistency (IoI) framework for detecting contradictions across digital forensic artifacts using CASE/UCO JSON-LD and SPARQL.

## Contents
- `RULES/` — SPARQL IoI signatures
- `TEMPLATES/` — JSON-LD templates (CASE/UCO + dfc-ext)
- `MAPPERS/` — artifact mapping scripts
- `CASES/` — case-specific mapping notes and snippets
- `RESULTS/` — performance and accuracy tables/plots
- `SCRIPTS/` — utility scripts (conversion, run helpers)
