# Dataset Summary

This repository distributes mapping templates, SPARQL IoI signatures, and redacted examples.

## Included
- JSON-LD templates (CASE/UCO + dfc-ext)
- Mapping scripts (CSV/XML -> JSON-LD)
- SPARQL rules
- Small redacted JSON-LD snippets per case
- Performance/accuracy tables

## Not Included
- Full raw CSVs (MFT/USN/Event logs)
- Full JSON-LD graphs derived from real systems
- Any personally identifying file paths

To reproduce full datasets, use the mapping scripts with your own CSVs or the curated Docker image.
